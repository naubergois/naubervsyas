# Loop do canal

O YouTube é a casa. Quem chega pelo corte e fica dois minutos no papo vale mais do que view que some no segundo 2. Este diretório é o cérebro que o agente lê antes de escolher rede, keyword ou fila.

Não substitui `CRESCIMENTO.md`. Aquele arquivo conta a história e o número que já saiu. Aqui mora a decisão operacional: o que entra, o que fica de fora, o que sobe esta semana.

## Ordem

0. `brand-profile.md` e `audience.md` — quem fala e pra quem.
1. `social-strategy.md`, `content-pillars.md`, `goals-and-kpis.md` — onde e com que meta.
2. `angulos.md` — qual recorte, não qual tese nova.
3. `social-seo.md`, `youtube-seo.md`, `instagram-seo.md`, `tiktok-seo.md`, `geo.md`, `hashtags.md` — como a busca acha.
4. `calendario.md`, `republicacao.md`, `perfis.md`, `fila.md` — o que sai.
5. `analytics.md`, `experimentos.md` — o que o número manda fazer depois.
